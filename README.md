Water Fix Custom - Projeto Dev Solidário

Website institucional estático desenvolvido para a empresa Water Fix Custom como parte do projeto "Dev Solidário" da disciplina de Programação Web.

🚀 Sobre o Projeto

Este é um projeto acadêmico que visa aplicar os conceitos de HTML5, CSS3 e JavaScript puros para construir uma presença online real e funcional para um pequeno negócio local.

A empresa beneficiada foi a Water Fix Custom, uma oficina especializada na restauração de interiores de caminhonetes (com foco na F-1000) e na venda de peças e acessórios automotivos customizados. O site serve como uma vitrine digital para seus produtos e serviços, ajudando a atrair novos clientes.

✨ Funcionalidades Principais

Design 100% Responsivo: Totalmente adaptável para desktops, tablets e celulares (Mobile-First).

Navegação Multi-página: O site é dividido em seções claras: Home, Produtos, Serviços e Contato.

Header Fixo (Sticky): O menu de navegação acompanha o usuário durante a rolagem, com um menu "hamburger" funcional no mobile.

Catálogo de Produtos: Página de "vitrine" com produtos organizados por categoria.

Páginas de Detalhe de Produto: Cada produto possui sua própria página com galeria de fotos interativa e descrição detalhada.

Links Diretos: Botões de "call-to-action" (CTA) para contato direto via WhatsApp e links para redes sociais (Instagram).

Semântica e Acessibilidade: Uso de tags HTML5 semânticas para melhor organização e acessibilidade.

💻 Tecnologias Utilizadas

Este projeto foi construído do zero, sem o uso de frameworks ou bibliotecas (como React, Bootstrap ou JQuery), para focar nos fundamentos do desenvolvimento web:

HTML5 Semântico

CSS3 (Flexbox, Grid Layout, Animações e Media Queries)

JavaScript (ES6+) (Manipulação do DOM para funcionalidades interativas como menu mobile e galeria de fotos)
